## 🛠️ PROJECTS

### ⚖️ [Evidential](https://github.com/TheWildEye/Evidential)
> **Forensic Chain of Custody Integrity Management**
* Developed a forensic evidence registry using SHA-256 cryptographic hashes, RBAC, and session-based authentication.
* Achieved ~35% faster validation via automated file registration & integrity verification routines.
* Fully aligned with BSA Section 63 & IEA Section 65B compliance standards.
* **Tech Stack:** `Python` `SHA-256` `Forensics` `RBAC` `Forensic Compliance`

### 🛡️ [QuantumShield](https://github.com/TheWildEye/QuantumShield)
> **Post-Quantum Secure OpenID Connect Framework**
* Designed and built a Post-Quantum Secure OpenID Connect protocol utilizing KEMTLS with ML-KEM-768.
* Selected as a Finalist in IIT Kanpur's HACKIITK 2026 (out of 9,000+ national participants).
* Implemented ML-DSA-65 JWT signing and SHA3-256 hashing to achieve ~44% faster handshake speeds.
* **Tech Stack:** `Python` `KEMTLS` `ML-KEM-768` `ML-DSA-65` `Post-Quantum Cryptography`

### 👁️ [TheWildEye FW](https://github.com/TheWildEye/TheWildEyeFW)
> **Unified Reconnaissance & OSINT Framework**
* Deployed a modular intelligence-gathering framework automating DNS, SSL, WHOIS, WAF, and email harvesting.
* Actively deployed across 1,000+ targets, reducing manual reconnaissance cycles by ~50%.
* Built custom HTTP probing and response header analysis modules for precise WAF product fingerprinting.
* **Tech Stack:** `Python` `OSINT` `WAF Detection` `Reconnaissance` `DNS/SSL Probing`

### 🐯 [TigerHunt (DirHunter)](https://github.com/TheWildEye/DirHunter)
> **Multithreaded Directory Brute-Forcer**
* Engineered a fast, cross-platform directory brute-forcer handling redirects and custom HTTP methods.
* Automates reconnaissance reporting with an interactive command-line interface.
* **Tech Stack:** `Python` `Multithreading` `HTTP Protocols` `Web Reconnaissance`
